换新电脑的时候，我没有用迁移助理把旧 Mac 整个搬过来，而是从一台干净的机器重新配起，因为这样正好能借机把攒下的应用和设置挨个过一遍，留下真正还在用的，其余的就让它们留在旧电脑上。这篇记下的就是这次配置的过程，按用途分成几组，每样东西后面跟一句为什么用它，再附上安装命令和配置。

这份清单主要是写给 Agent 读的，所以每一步都尽量写成可以直接照做的命令和路径，少了些解释。如果是人自己照着配置，就不必全盘照搬，按自己的习惯挑着用就好。

## 开始之前

> 这两步要手动完成，后面的清单都交给装好的 Claude 去执行。

- Claude 桌面应用：从 [claude.ai/download](https://claude.ai/download) 下载，拖进「应用程序」后打开并登录
- 旧电脑的文件用外置硬盘迁移，不走云端

## macOS 设置

System Settings 里按面板改，每行一个面板：

- **Appearance**: Dark, Show scroll bars → Always
- **Desktop & Dock**: smaller Size, Automatically hide and show the Dock, Show indicators for open applications on, Show suggested and recent apps in Dock off, Hot Corners all set to "–"
- **Battery**: Show Percentage on
- **Displays**: Night Shift on
- **Touch ID & Password**: add fingerprint
- **Notifications**: off for all apps except Calendar
- **Siri**: off
- **Trackpad**: Tracking speed fastest, Tap to click on, Look up & data detectors off, More Gestures → Notification Centre off
- **Keyboard**: Press 🌐 key to → Do Nothing, Keyboard Shortcuts → Mission Control all off
- **Keyboard → Text Input**: Capitalise words automatically off, Add full stop with double-space off, Use smart quotes and dashes off, double quotes `"`, single quotes `'`
- **General**: Sharing → all services off, Storage → delete GarageBand, its sound library and iMovie
- **Privacy & Security**: FileVault on
- **Accessibility**: Pointer Control → Trackpad Options → Scrolling speed fastest

Dock 和访达：

- **Dock**: drag unused apps off the Dock
- **Finder → Settings**: New Finder windows show Downloads, Show these items on the desktop all off, Sidebar → all Favourites on and add Library, Tags all off, Advanced → Show all filename extensions on, Remove items from the Bin after 30 days on
- **Finder → View**: Show Preview

界面里找不到的设置用 `defaults` 改：

```bash
# 截图存成 JPG
defaults write com.apple.screencapture type jpg
# 预览不恢复上次打开的文件
defaults write com.apple.Preview ApplePersistenceIgnoreState YES
# 显示资源库
chflags nohidden ~/Library
# 访达显示隐藏文件、路径栏和状态栏
defaults write com.apple.finder AppleShowAllFiles YES
defaults write com.apple.finder ShowPathbar -bool true
defaults write com.apple.finder ShowStatusBar -bool true
killall Finder
```

电脑名：

```bash
# 需要用户操作：提供电脑名（只用字母、数字和连字符），输入 sudo 密码
sudo scutil --set ComputerName "<电脑名>"
sudo scutil --set LocalHostName "<电脑名>"
sudo scutil --set HostName "<电脑名>"
```

## 基础开发工具

**Xcode Command Line Tools**：git、clang 这些编译工具都在里面，Homebrew 也依赖它。命令执行后会弹出系统安装窗口，需要手动点「安装」并等它下载完。

```bash
# 已经装过的话会直接报错提示，可以跳过
xcode-select --install
# 能打印出 /Library/Developer/CommandLineTools 就说明装好了
xcode-select -p
```

**Homebrew**：后面几乎所有应用和命令行工具都用它来装。

```bash
# 需要用户操作：输入 sudo 密码，按回车确认
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
# Apple Silicon 上 brew 装在 /opt/homebrew，默认不在 PATH 里
echo 'eval "$(/opt/homebrew/bin/brew shellenv zsh)"' >> ~/.zprofile
eval "$(/opt/homebrew/bin/brew shellenv zsh)"
brew update
```

**kitty**：终端，配置全写在一个文本文件里，分屏和快捷键都能自己定。字体用 JetBrains Mono 和它的 Nerd Font 版本，eza 和 starship 的图标要靠后者显示。

```bash
brew install --cask kitty font-jetbrains-mono font-jetbrains-mono-nerd-font
```

`~/.config/kitty/kitty.conf`：

```bash
mkdir -p ~/.config/kitty
cat > ~/.config/kitty/kitty.conf <<'EOF'
# Nerd Font，eza 和 starship 的图标要用
font_family JetBrainsMono Nerd Font
font_size 15.0

# 全屏不开新桌面，⌘ Enter 切换
macos_traditional_fullscreen yes
map cmd+enter toggle_fullscreen

# 关窗口不确认
confirm_os_window_close 0

# 单标签页隐藏标签栏，不调暗未聚焦的分屏
tab_bar_min_tabs 2
inactive_text_alpha 1.0

background_opacity 0.7

# 分屏沿用当前目录
enabled_layouts splits,stack
map cmd+d launch --location=vsplit --cwd=current
map cmd+shift+d launch --location=hsplit --cwd=current

# ⌥ ←/→ 按词跳，⌘ ←/→ 行首行尾，⌘ ⌫ 删整行
macos_option_as_alt yes
map alt+left send_text all \x1bb
map alt+right send_text all \x1bf
map cmd+left send_text all \x01
map cmd+right send_text all \x05
map cmd+backspace send_text all \x15

# ctrl+shift+p n 打开「文件:行号」用的编辑器
editor nvim
EOF
```

**zinit 和 Shell 工具**：zinit 负责加载 zsh 插件，补全、自动建议和语法高亮都靠它，Oh My Zsh 里的 git 和 eza 插件也是单独引入的。eza 替代 ls，bat 替代 cat，fzf 用来搜历史命令，zoxide 按访问频率跳目录，starship 是提示符，neovim 当 vi 用。

```bash
brew install eza bat fzf zoxide starship neovim
```

`~/.zshrc`：

```bash
cat > ~/.zshrc <<'EOF'
ZINIT_HOME="${XDG_DATA_HOME:-$HOME/.local/share}/zinit/zinit.git"
[ ! -d "$ZINIT_HOME" ] && mkdir -p "$(dirname "$ZINIT_HOME")" && git clone https://github.com/zdharma-continuum/zinit.git "$ZINIT_HOME"
source "$ZINIT_HOME/zinit.zsh"

zinit light zsh-users/zsh-completions
zinit light zsh-users/zsh-autosuggestions
zinit light zsh-users/zsh-syntax-highlighting
zinit snippet OMZP::git

# ls、ll、la 等 eza 缩写
zstyle ':omz:plugins:eza' 'icons' yes
zstyle ':omz:plugins:eza' 'git-status' yes
zinit snippet OMZP::eza

alias ip="ipconfig getifaddr en0"

alias tree="eza --tree --icons"
alias cat="bat"
alias vi="nvim"

autoload -U compinit && compinit

# mise 的官方脚本装在这里，系统默认的 PATH 里没有它
export PATH="$HOME/.local/bin:$PATH"

[ -x ~/.local/bin/mise ] && eval "$(~/.local/bin/mise activate zsh)"

# ⌃R 用 fzf 模糊搜索历史命令，z 按访问频率跳到常去的目录
eval "$(fzf --zsh)"
eval "$(zoxide init zsh)"

eval "$(starship init zsh)"
EOF
```

**Git**：Homebrew 的版本比系统自带的新。

```bash
brew install git
# 需要用户操作：提供 Git 提交用的名字和邮箱
git config --global user.name "<名字>"
git config --global user.email "<邮箱>"
git config --global init.defaultBranch main
git config --global alias.lg "log --color --graph --pretty=format:'%Cred%h%Creset -%C(yellow)%d%Creset %s %Cgreen(%cr) %C(bold blue)<%an>%Creset' --abbrev-commit"
git config --list
```

**SSH 和 GitHub CLI**：用 gh 登录 GitHub，顺便把新生成的公钥传上去。

```bash
brew install gh
mkdir -p ~/.ssh
# 需要用户操作：设置口令，口令存放在安全的地方
ssh-keygen -t ed25519 -C "github" -f ~/.ssh/github
# 需要用户操作：输入刚才的口令，之后由钥匙串保存
ssh-add --apple-use-keychain ~/.ssh/github
# 需要用户操作：在浏览器里完成 GitHub 授权
gh auth login
gh ssh-key add ~/.ssh/github.pub -t github
```

`~/.ssh/config`：

```bash
cat > ~/.ssh/config <<'EOF'
Host github.com
  AddKeysToAgent yes
  UseKeychain yes
  IdentityFile ~/.ssh/github
EOF
```

**mise**：一个工具管 Node、Go、Rust 和 pnpm 的版本。

```bash
# 装到 ~/.local/bin
curl https://mise.run | sh

# 当前 shell 里找到 mise 和它装的 node、go、cargo
export PATH="$HOME/.local/bin:$HOME/.local/share/mise/shims:$PATH"

# 写进 ~/.config/mise/config.toml
mise use -g node@lts
mise use -g go@latest
mise use -g rust@latest
mise use -g pnpm@latest

npm install -g npm@latest

# 需要用户操作：登录 npm 账号，发布包时才用得上
npm adduser
```

装完之后 `~/.config/mise/config.toml` 里会是这样：

```toml
[tools]
node = "lts"
go = "latest"
rust = "latest"
pnpm = "latest"
```

**mr boxington**：为我配置 [mr-boxington.jdx.dev](https://mr-boxington.jdx.dev)，让它接管所有的 Rust targets，根据过往的构建情况和机器配置，设置合适的缓存大小和 GC 时间。如果机器上已经配置了 mise，就使用 mise 集成；如果没有，就使用 rustup 的原生集成。
